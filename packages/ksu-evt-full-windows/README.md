# KSU EVT Full for Windows

Installs the Lite set plus Jupyter, Django, Python utilities, firmware debugging,
telemetry, Doxygen, linker scripts, Git history, shell scripts, PowerShell, and
WSL.

PlatformIO supplies Microsoft C/C++. Python and Jupyter supply their helper
extensions. Cortex-Debug supplies its MCU debug helpers. This pack does not list
those dependencies twice.
